# Build requirement update

On 22 October, Isreal Hosana published an update in the moderated [official announcement channel](https://hackathon.genai.works/messages?c=01a01e1c-8ff8-7c95-8191-618849846e28): Cursor is optional and other AI coding tools are permitted. No free Cursor credits are provided. At least one Meterless Engine must still operate in a product feature, demonstrated by a test or live demo.

Remus Ranca, GenAI Works Education Operations Lead, confirmed this in Help Cursor. The public event page still contains older Cursor requirements in 5.1/6.4; this discrepancy is retained in the audit. This project uses Codex, and H-MEM is exercised by both tests and the real sponsor workflow. Cursor use is not claimed.
