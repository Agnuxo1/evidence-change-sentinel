# Working description, not yet submitted

Evidence Change Sentinel helps funding-call reviewers see which assessments need another look when a source changes. Each criterion links to an exact passage, URL and source hash. A changed clause or applicant fact invalidates its dependent assessment; unaffected assessments remain traceable. Missing evidence, unfamiliar wording and new unmapped clauses go to human review.

The working offline prototype uses the official Meterless H-MEM reference for provenance, memory reuse and audit history. Its synthetic demo shows a company-size limit changing from 50 to 20 while date and region checks are preserved. Local checks: 24 application tests, 13 H-MEM conformance checks and 55 controlled synthetic evaluation cases. These are not real-world accuracy measurements.

Zetaris REST retrieval and a Meterless Nightshift proposal/validator revision loop are implemented as adapters, but authenticated live integration and Cursor development verification remain pending. No NVIDIA model use is claimed. Existing concept/planning and the licensed H-MEM reference are declared pre-existing components; the new application code was written during the build window. This snapshot is a research prototype, not an official funding eligibility decision.
